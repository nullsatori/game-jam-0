# JamArt

Team art (meshes, textures, sounds) lives here; package paths start with
/Game/JamArt/. Everything in this folder is stored in Git LFS, and .uasset/.umap
files are lockable: `git lfs lock <path>` before editing, unlock after push.
See the "Тяжёлый арт и Git LFS" section of the top-level README.md.

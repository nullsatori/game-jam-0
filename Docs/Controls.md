Единая таблица текущих привязок. Здесь описаны реализованные действия; управление будущими механиками добавляется после выбора и реализации. Правила самих механик — в [индексе систем](README.md).

Пешка одна (`AOSZeroGPawn`), клавиши привязаны в
`AOSZeroGPawn::SetupPlayerInputComponent`. Что делает клавиша, зависит от
режима движения (`Float` — невесомость, `Walk` — на ногах в зоне гравитации,
`Ladder` — на лестнице, `Hang` — держусь за неподвижное) и от того, что в руках
(ствол, инструмент, тело, пусто) — [ZeroG](ZeroG.md#режимы-движения),
[«Руки»](ZeroG.md#руки).

| Клавиша | Действие |
|---|---|
| Мышь | взгляд (`LookSensitivity` 0.7; в оптике СВ-98 медленнее во столько раз, во сколько она увеличивает). В невесомости — свободные перевороты без предела по тангажу |
| Q / E (держать) | крен в невесомости; в гравитации — ничего |
| W A S D | `Float`: маневровые относительно взгляда, разгон до 5 м/с вдоль ввода. `Walk`: ходьба. `Ladder`: лаз. `Hang`: рука — к руке подтянуться, поперёк раскачаться |
| Space | `Float`: маневровые вверх. `Walk`: прыжок; в воздухе над планетоидом — реактивный выход из его гравитации. `Ladder`: толчок от лестницы. `Hang`: рука |
| Left Ctrl | `Float`: маневровые вниз. `Hang`: рука. На ногах — ничего |
| X (держать) | стабилизатор: плавно гасит скорость; только в `Float` |
| ЛКМ | ствол: выстрел (пистолет: держать — автоогонь). Стяжка: линия (первый щелчок — к поясу, второй — закрепить). Сварка: горелка, пока зажата. Тело в руках: бросок |
| ПКМ | ствол: прицеливание, пока зажата; свободное тело в досягаемости — взять (ствол убирается сразу, «без оружия»; отпустил тело — ствол достаётся). Инструмент или ни одного ствола: взять тело, по неподвижному — держаться. Держа тело или держась — отпустить. На лестнице — ничего |
| Средняя кнопка (держать) | прицеливание; ствол поднимается, только пока он в руке; никогда не хватает |
| Колесо | ствол: следующий; держа тело — отпустить его и следующий ствол. Стяжка: длина последней линии (по 25 см). Сварка — ничего |
| R | ствол: перезарядка (во время цикла выстрела — после него). Стяжка: снять линию под прицелом (иначе последнюю). Сварка: сварка / резка. Держа тело — ничего |
| Tab | ствол в руке: держать ≥ 0.25 с — меню обвесов на стене ([Attachments](Attachments.md)): колесо — выбор, отпустить Tab или ЛКМ — надеть / снять; ПКМ, средняя, R — ничего; цифра, инструмент, захват — меню гаснет без применения; в перезарядке не открывается. Тап — тумблер ЛЦУ / фонаря на стволе. Без ствола — ничего |
| 1..N | стволы по порядку `UOSWeaponsComponent::Weapons` (сейчас 1 — пистолет, 2 — дробовик, 3 — снапа СВ-98): убирает инструмент; если ствол подобран — достаёт его с анимацией смены, держа тело — отпускает его |
| N+1 / N+2 (сейчас 4 / 5) | стяжка / сварка ([HullRepair](HullRepair.md)): взять (тело отпускается); второй раз — убрать и вернуть ствол |
| F | взаимодействие (пикап, дверь, баллон, рубильник); если не с чем — толчок от того, что в 1.8 м перед глазами; держа тело — толчок вместе с ним, а без опоры — оттолкнуть само тело |
| Left Shift (держать) | просчёт пути толчка, отдачи или броска |
| Left Alt | крюк-кошка, после подбора: зацепить то, что под прицелом в 30 м / отцепить; с лестницы не цепляется |
| V (держать) | замедление времени |
| G | лом: тег `MK.Crowbar` на пешке ([Fastener](Fastener.md)) |
| F6 / Shift+F6 | отладочное меню ([DebugMenu](DebugMenu.md)): F6 — открыть / закрыть (курсор и клавиши в меню, игра идёт; Esc закрывает), Shift+F6 — закрепить полупрозрачной панелью поверх игры, ввод остаётся в игре. В Shipping меню нет |

Цифры берутся из списков: стволы — 1..N по порядку списка стволов, инструменты
— сразу за ними (`AOSZeroGPawn::GetToolSlot`; четвёртый ствол займёт 4,
инструменты сдвинутся на 5 и 6). Клавиши рук (ЛКМ, ПКМ, колесо, R) решает одна
таблица `AOSZeroGPawn::Route`; проверка — `os.Hands.Probe`.

# Дизайн игры

Нетехнические документы: замысел, прохождение, правила механик для игрока, лор и открытые дизайн-решения. Устройство кода, настройка акторов и команды проверок находятся в [технической документации](../README.md).

| Документ | Что описывает |
|---|---|
| [MVP](MVP.md) | принципы игры, локации, целевое прохождение и обязательный объём |
| [Progression](Progression.md) | выдача инструментов, доступ к отсекам, связи механик и подсказки |
| [Fuel](Fuel.md) | сбор, хранение, заправка и поджог топлива |
| [Navigation](Navigation.md) | доставка и замена навигационного модуля |
| [Collectibles](Collectibles.md) | дневник, жетоны, артефакты и правила чтения/учёта |
| [Boss](Boss.md) | пробуждение планеты, захват корабля, освобождение и вылет |
| [Дневник](Lore/Diary.md) | текст находки и содержащиеся в нём подсказки |

Правила ведения документации — в [общем индексе](../README.md#как-обновлять-документацию). Старые планы и сверки — в [разделе истории](../README.md#история).

# game-jam-0 — «Почини и улети»

Игра для геймджема: тема **Trash**, предмет **Rocket**. Unreal Engine 5.8, C++.

Шутер от первого лица с физическими взаимодействиями в невесомости. Игрок исследует место аварии, добывает инструменты и восстанавливает корабль. Перемещение, доставка деталей и решение препятствий опираются на толчки, отдачу, захват и броски предметов.

## Текущий прототип

Есть физическое перемещение в невесомости и гравитации, перенос предметов, три вида оружия с отдачей, ремонт обшивки, живые стены и стаи летунов. Целевой цикл MVP ещё собирается: состояние отдельных механик описано на [страницах систем](Docs/README.md), недостающие связи — в [Progression](Docs/Vision/Progression.md).

| Карта | Назначение |
|---|---|
| `Lvl_Jam_Ship` | Стартовая локация, правится руками; устройство и ограничения — [Ship-Blockout](Docs/Ship-Blockout.md) |
| `Lvl_Jam_Range` | Тир: оружие, живые стены, переход из гравитации в невесомость |
| `Lvl_Jam_ZeroG` | Полигон физических взаимодействий и движения в невесомости |
| `Lvl_Jam_TestRoom` | Стенд перенесённых интерактивных механизмов |

Все карты используют `AJamShipGameMode` и физическую пешку `AJamZeroGPawn`. Подробности — [ShipMode](Docs/ShipMode.md), проверки — [Probes](Docs/Probes.md).

## Открыть и запустить

1. Установить UE 5.8, Visual Studio с C++ и Git LFS.
2. Выполнить `git lfs install`; после клонирования в корне репозитория — `git config lfs.setlockablereadonly false`.
3. Открыть `MKJamStarter.uproject`, согласиться на сборку модуля и запустить стартовую карту.

**Карту `Lvl_Jam_Ship` не пересобирать через `Scripts/build_ship.py`: он стирает ручную работу.** Правила работы с картами, LFS, командами сборки и MCP-плагинами — в [Development](Docs/Development.md).

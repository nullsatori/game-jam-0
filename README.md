# game-jam-0

Игра для двухдневного геймджема. Тема — **Trash**, предмет — **Rocket**.
Unreal Engine 5.8, C++.

## Концепт

Космос, мусор, корабль, нулевая гравитация. Шутер от первого лица.

Главное — физика: ощущение перемещения, смешные столкновения, движение,
которое можно просчитать.
- Двигаешься толчками от мусора и отдачей стволов.
- Мусор можно толкать и швырять в цели по инерции.
- Лут физический: большую деталь тащишь на себе или толкаешь к кораблю.
- На этих механиках строятся простые пространственные головоломки.

Подробно: [Concept](Docs/Concept.md).

## Что реализовано

Карта `Lvl_Jam_Ship` (стартовая) — серый блок-аут концепта: каюта с
гравитацией и шлюзом, разбитый корабль, листы обшивки, топливо за поясом
камней, навигационный модуль и дробовик на планетоиде, груз. Пешка одна и
та же физическая: в каюте и на планетоиде она ходит (WASD, прыжок Space), а
снаружи летает в невесомости, без подмены пешки. По планетоиду ходишь
ногами, как в меню Psychonauts: гравитация к центру шара, уйти — прыжок и
второй прыжок в воздухе (реактивный толчок). Планетоид — живой шар 80 м с
рельефом (сделан в Blender), под ногами хлюпает и хрустит мясо: четыре кратера, дно которых — живая мембрана,
она открывается дробовиком в шахту; сквозные пещеры с живыми пробками; за
пробками и под кратером — груз и кислород. Свет: бирюзовая
звезда, фиолетовое небо со звёздами, тёплая каюта. Подробно:
[Ship-Blockout](Docs/Ship-Blockout.md).

Карта `Lvl_Jam_ZeroG` — полигон невесомости:
- **Невесомость.** Тело 100 кг, скорость сохраняется. Взгляд — мышью и Q/E (крен),
  физическое тело не вращается: удары и трос его не крутят.
- **Маневровые** WASD, Space, Ctrl. Основное движение: разгон до 5 м/с
  вдоль ввода, кислород не тратят. X — стабилизатор, плавно гасит скорость.
- **Толчок** (F): от того, что перед глазами. От лёгкого мусора он
  улетает, от тяжёлого улетаешь ты.
- **Захват** (ПКМ): физическая связь с предметом, предмет держится перед
  камерой. Тяжёлый тянет тебя, бросок (ЛКМ) отталкивает в обратную сторону.
- **Ремонт обшивки** (4 — стяжка, 5 — сварка, ПКМ по корпусу — держаться):
  лист притягивают к пробоине линиями и проваривают по контуру. Подробно:
  [HullRepair](Docs/HullRepair.md).
- **Крюк-кошка** (Left Alt): зацепиться в 30 м и подтянуться (или подтянуть лёгкое).
- **Стволы с отдачей** (1/2/3, R — перезарядка): пистолет, дробовик, снапа.
  Отдача двигает тебя, попадание толкает цель.
- **Просчёт траектории** (держать Shift): путь толчка, отдачи или броска с
  первым отскоком.
- **Столкновения:** урон, звук и тряска. Быстрый тяжёлый предмет бьёт
  стекло.
- **Кислород:** тратится только на дыхание, баллоны пополняют.
- **Стыковочная зона корабля:** считает детали с тегом `Ship.Part`.
- **Живая стена:** ниша у западной стенки закрыта вскрытой мышечной тканью в
  ржавой раме (меш из Blender, текстуры владельца). Пистолет её только
  ранит, рана схлопывается за полсекунды и пролезть не даёт, а дробовик вырывает дыру с рваным волокнистым краем, которая
  держится ~3 с и сходится от краёв. За стеной лежит деталь корабля.
  На корабле таким же коконом оплетён модуль навигации.
- **Читаемость движения:** FOV 134 и линза бодикама из MindKore, пыль вокруг камеры, метка курса и
  скорости на HUD.

Все числа — в настройках компонентов. Описание с числами:
[ZeroG](Docs/ZeroG.md) · [Tether-Prediction](Docs/Tether-Prediction.md) ·
[DockZone](Docs/DockZone.md) · [RecoilWeapons](Docs/RecoilWeapons.md)

## Открыть и собрать

1. Установить UE 5.8, Visual Studio с C++ и [Git LFS](https://git-lfs.com).
   Выполнить `git lfs install`, затем клонировать репозиторий.
2. Открыть `MKJamStarter.uproject`. Редактор предложит собрать модуль —
   согласиться. Можно собрать и из PowerShell:

   ```powershell
   & "C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\Build.bat" MKJamStarterEditor Win64 Development -Project="<путь>\MKJamStarter.uproject" -WaitMutex
   ```

Карты собираются скриптами `Scripts/build_zerog.py` и
`Scripts/build_test_room.py`:

```
UnrealEditor-Cmd.exe <путь>\MKJamStarter.uproject -ExecutePythonScript="<путь>/Scripts/build_zerog.py" -unattended -nop4 -nosplash -nullrhi
```

Арт планетоида и живой стены делают скрипты Blender (`Scripts/blender/*.py`,
`blender.exe -b --python <скрипт> -- <папка для FBX>`), FBX импортирует
`Scripts/jam_import_meshes.py`; в репозитории только `.uasset`.

Модуль называется `MindKore`: так перенесённый код работает без правок.
Новый код — файлы `Jam*.h/.cpp` в `Source/MindKore`.

## MCP-плагины

Для работы ИИ-ассистента с редактором (Claude Code, Codex, Cursor) нужны два
Editor-плагина. В git их нет (`Plugins/` в `.gitignore`), в `.uproject` они
помечены `Optional`: без них проект открывается и собирается как обычно.
Каждый ставит их сам, ровно этих версий:

1. **UE_MCP_Bridge** из npm-пакета `ue-mcp`, версия `1.4.8-beta.2`. Нужен
   Node.js. Из корня репозитория, при закрытом редакторе:

   ```powershell
   npx -y ue-mcp@1.4.8-beta.2 deploy MKJamStarter.uproject
   ```

2. **VibeUE**, снимок `dc051be7c49b08e613ca7a2196fe9f39c9b52119` из
   [kevinpbuckley/VibeUE](https://github.com/kevinpbuckley/VibeUE):

   ```powershell
   git clone https://github.com/kevinpbuckley/VibeUE.git Plugins/VibeUE
   git -C Plugins/VibeUE checkout dc051be7c49b08e613ca7a2196fe9f39c9b52119
   ```

3. Собрать проект (команда из раздела «Открыть и собрать») и открыть редактор.

Настройка клиента уже в репозитории:

- `.mcp.json` регистрирует `ue-mcp@1.4.8-beta.2` и `unreal-mcp` —
  встроенный MCP-сервер редактора `http://127.0.0.1:8000/mcp`, на нём
  работают инструменты VibeUE. Порт 8000 один на машину: два открытых
  редактора с MCP его не поделят, ответит только один из них.
- Путь к проекту в `.mcp.json` относительный, поэтому клиент запускать из
  корня репозитория. Иначе — свой абсолютный путь к `.uproject` в локальной
  настройке клиента (для Claude Code: `claude mcp add --scope local ue-mcp -- npx -y
  ue-mcp@1.4.8-beta.2 <путь>/MKJamStarter.uproject`).
- `ue-mcp.yml` — общая настройка сервера: `server.mode: in-process`, сервер
  живёт вместе с клиентом и не подключается к чужому редактору. Личные
  правки — в `ue-mcp.local.yml`, он не коммитится.

Обновление: поменять версию в команде `deploy`, в `.mcp.json` и здесь, снова
выполнить `deploy` и пересобрать.

## Git LFS

- Все двоичные файлы (`.uasset`, `.umap`, `.fbx`, `.wav`, `.png` и т. д.)
  идут через LFS. Новый арт кладётся в `Content/JamArt/`.
- `.uasset` и `.umap` блокируемые. Перед правкой —
  `git lfs lock <файл>`, после push — `git lfs unlock <файл>`. Кто что держит:
  `git lfs locks`.
- Квота LFS общая на аккаунт и почти занята, поэтому текстуры не больше 2K,
  исходники (`.blend`, `.psd`) в репозиторий не класть.
